## 🎯 意图类型定义

```
IntentType (Enum)
├─ QUERY (查询)
│  └─ 示例: "订单状态是什么？", "显示用户列表"
│  └─ 必需实体: {对象, 查询内容}
│
├─ OPERATION (操作)
│  └─ 示例: "添加新用户", "删除这条记录"
│  └─ 必需实体: {对象, 操作类型, 操作细节}
│
├─ COMPLAINT (投诉)
│  └─ 示例: "登录功能坏了", "系统报错"
│  └─ 必需实体: {对象, 问题现象}
│
├─ REQUIREMENT (需求)
│  └─ 示例: "能不能增加导出功能"
│  └─ 必需实体: {对象, 需求细节}
│
├─ HELP (求助)
│  └─ 示例: "怎么使用这个功能"
│  └─ 必需实体: {对象, 目标}
│
└─ UNKNOWN (未知)
   └─ 无法识别的意图
```

```
实体类型 (Entity Types)
├─ 通用实体 (Common)
│  ├─ 对象: 功能、模块、系统名称
│  ├─ 时间: 时间相关信息
│  ├─ 平台: 平台或设备类型
│  └─ 范围: 影响范围
│
├─ 投诉类专属 (COMPLAINT)
│  └─ 问题现象: 具体的问题描述
│
├─ 操作类专属 (OPERATION)
│  └─ 操作细节: 具体的操作说明
│
├─ 需求类专属 (REQUIREMENT)
│  └─ 需求细节: 具体的需求描述
│
└─ 求助类专属 (HELP)
   └─ 目标: 用户想达成的目标
```

## 📊 语义评估算法

### 完整度 (Completeness)

```python
completeness = len(entities) / len(required_entities)

示例:
  required = {对象, 问题现象}  # 2个
  entities = {对象: "登录功能"}  # 1个
  completeness = 1 / 2 = 0.50
```

### 置信度 (Confidence)

```python
base_confidence = min(len(user_input) / 20, 1.0) * 0.5

if entities:
    entity_confidence = min(len(entities) / 3, 1.0) * 0.5
else:
    entity_confidence = 0

confidence = base_confidence + entity_confidence

示例:
  user_input = "这个东西有问题" (7字)
  base = (7/20) * 0.5 = 0.175
  entity = 0 (无实体)
  confidence = 0.175 ≈ 0.18
```

### 可执行性 (Is Executable)

```python
is_executable = (
    completeness >= 0.7 and
    confidence >= 0.6 and
    intent != IntentType.UNKNOWN
)

示例:
  completeness = 0.80
  confidence = 0.75
  intent = COMPLAINT
  is_executable = True
```

## 🔀 路由决策逻辑

### route_by_clarity

```python
if state.semantic_info.completeness >= 0.7 and \
   state.semantic_info.confidence >= 0.6:
    return "finalize"  # 足够明确，结束
else:
    return "generate_questions"  # 需要澄清
```

### route_after_clarification

```python
if state.is_clear:
    return "finalize"  # 已明确，结束
elif state.round_count >= 3:
    return "finalize"  # 超过3轮，强制结束
else:
    return "continue"  # 继续澄清
```

## 💡 性能优化策略

### 1. 模型选择
```
生产环境: gpt-3.5-turbo (快速、成本低)
开发环境: Ollama qwen2.5 (免费、本地)
高精度需求: gpt-4 (准确率最高)
```

### 2. Temperature 设置
```
temperature=0  # 确保输出稳定性和一致性
```

### 3. Prompt 优化
```
• 精简描述，减少 token 使用
• 使用示例而非长篇说明
• 明确输出格式，减少重试
```

### 4. 缓存策略
```python
# 可选：缓存常见查询
@lru_cache(maxsize=100)

    return llm.invoke(text)
```
